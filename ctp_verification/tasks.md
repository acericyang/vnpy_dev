# CTP 程序化交易客户端接入验证 — 逐任务操作手册

> 配套：`task_config.yaml`（Genesis.exe 任务清单，编号 0–32）｜`设计文档.md`（实现原理）｜`patches/README.md`（网关补丁）
> 截图：全程使用飞泰截图工具（Genesis.exe），归档到 `screenshots/`，命名 `NN_标题_说明.png`

## 〇、启动与准备

```bash
# 仓库根目录执行（CTPTEST 评测环境 6666@61.186.254.137）：
python examples/veighna_trader/run_ctptest.py
# 或（vnpy_ctp 网关环境，注意两者 DLL 不兼容、不能同时运行）：
python examples/veighna_trader/run.py
```

1. 启动后：菜单「功能」→「程序化交易监控」，**保持该窗口全程打开**（预警弹窗、连接状态、统计都展示在此）。
2. 「系统」→「连接CTPTEST」，凭据已存于 `.vntrader/connect_ctptest.json`（连接对话框含密码，截图避开）。
3. 开场把「阈值与预警」页的三个阈值先设为高值（如 100/100/50），到 Phase 4 再改小演示，完成后调回。
4. 选合约：优先**非上期所**（避开平今/平昨复杂度，如 DCE/CZCE 品种）；用 SHFE 品种平仓时注意选「平今」。合约可从「帮助→查询合约」查最小变动价位与单笔最大手数（补丁后为柜台真值）。
5. 开场可先点一次「重置统计」，保证计数从零开始、证据干净。

### 冒烟自检（正式验证前 5 分钟）

- 连接后状态条双通道变绿（交易/行情「就绪」）；
- 交易部件挂 1 笔远价限价单（低于买一价 20–30 个最小变动价位）→ 监控页「报单笔数」+1、委托明细出现新行；
- 委托页双击撤掉 → 「撤单笔数」「撤单成功」各 +1；
- 故意输错价格（如 tick=1 输 `xxx.5`）报单 → 弹「本地拒绝」提示、错误信息页本地拒绝表 +1。
四项都对即可开始正式任务。

## 附：常见问题

- **弹窗太多干扰操作**：阈值页可临时关闭「预警弹窗」（保留声音与日志，不影响证据）。
- **重复报单双成交风险**：提示模式下两笔都真实进交易所，演示完立即撤余单；也可切换「拦截」模式演示（第二笔不发柜台）。
- **批量撤单笔数多**：每批 10 笔、间隔 1 秒自动分批，防柜台流控。
- **统计需要归零重演**：点「重置统计」（会写【统计重置】日志，属正常留痕）。
- **改单**：批量撤单页选中一行 →「改单」→ 新价量确认（= 撤原单 + 真实重报，两笔都送达柜台）。
