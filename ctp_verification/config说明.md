# task_config.yaml 配置文件说明

## 文件概述

`task_config.yaml` 是 Genesis 程序的任务配置文件，用于定义所有测试任务的标题和详细说明。

## 文件格式

### 基本结构

```yaml
# 任务说明配置文件
# 每个任务包含标题和内容

0:
  title: 任务标题
  content: |
    任务说明内容
    可以包含多行文本
    支持换行和缩进

1:
  title: 另一个任务标题
  content: |
    另一个任务的说明内容
```

### 格式规则

1. **任务编号**：从 0 开始的整数（0, 1, 2, ...）
2. **title**：任务标题，字符串类型
3. **content**：任务详细说明，使用 `|` 符号支持多行文本
4. **缩进**：使用 2 个空格进行缩进
5. **注释**：使用 `#` 符号添加注释

## 注意事项

### 1. 编码格式
- **必须使用 UTF-8 编码**
- 支持中文、英文等所有字符

### 2. 任务编号
- **从 0 开始**：第一个任务的编号是 0，不是 1
- **连续编号**：任务编号必须连续，不能跳号
- **总任务数**：默认为 33 个任务（0-32）

### 3. 内容格式
- **使用 `|` 符号**：支持多行文本
- **保持缩进**：使用 2 个空格进行缩进
- **避免特殊字符**：避免使用 YAML 特殊字符（如 `:`、`-` 等）

### 4. 文件保存
- **保存为 UTF-8**：确保文件编码正确
- **使用文本编辑器**：推荐使用 VS Code、Notepad++ 等编辑器
- **避免 Word**：不要使用 Word 等富文本编辑器

## 动态加载

程序支持动态加载配置文件，修改配置后：

1. **切换任务**：点击任意任务按钮，程序会自动重新加载配置
2. **点击刷新配置**：点击界面上的"刷新配置"按钮
3. **无需重启**：配置更改立即生效，无需重启程序

## 默认配置

如果配置文件不存在或加载失败，程序会使用默认配置：

```yaml
任务 {序号}:
  title: 任务 {序号}
  content: |
    任务 {序号} 的说明内容
    
    测试目的：完成相关测试任务。
    测试步骤：
    1. 按照要求执行测试。
    2. 记录测试结果。
    3. 上传相关截图。
    
    图片要求：
    包含相关测试步骤的截图。
```

## 常见问题

### Q1: 修改配置文件后没有生效？
**A:** 请点击"刷新配置"按钮或切换任务，程序会自动重新加载配置文件。

### Q2: 配置文件格式错误怎么办？
**A:** 程序会自动使用默认配置，请检查 YAML 格式是否正确。

### Q3: 如何添加新任务？
**A:** 在配置文件中添加新的任务编号（如 33、34 等），并设置相应的 title 和 content。

### Q4: 如何删除任务？
**A:** 直接删除对应的任务编号即可，但建议保留连续的编号。

### Q5: 配置文件在哪里？
**A:** 配置文件位于 `Genesis.exe` 所在目录下的 `task_config.yaml`。
